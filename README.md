# 🎓 Muthura Academy

A modern, responsive educational institute website built using **React**, **TypeScript**, **TanStack Start**, and **Tailwind CSS**. The website is designed to provide students with an engaging experience while showcasing courses, internships, achievements, testimonials, and contact information.

🌐 **Live Demo:** https://muthura-academy.onrender.com

---

## 📖 Overview

Muthura Academy is a professional training institute dedicated to empowering students with industry-ready skills through practical learning, internships, and expert mentorship.

This website serves as the official online platform for the academy where visitors can:

- Explore available courses
- Learn about the academy
- View student achievements
- Check internship opportunities
- Contact the academy
- Locate the institute using Google Maps

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/JAshwinDev/muthura-academy-online.git
```

Move into the project

```bash
cd muthura-academy-online
```

Install dependencies

```bash
npm install
```

Start Development Server

```bash
npm run dev
```

Build for Production

```bash
npm run build
```

Preview Production Build

```bash
npm run preview
```
